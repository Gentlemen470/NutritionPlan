# NutritionPlan

NutritionPlan is a desktop application built with Electron. It helps users search for food, view nutritional information, calculate nutrition based on portion sizes, and manage their daily food intake.

## Features

- Search for food and view nutritional information.
- Calculate calories, protein, carbohydrates, and fat based on portion size.
- Get food suggestions based on different dietary preferences.
- Add, view, update, and delete food diary records.
- Save food diary records and suggestions using Local Storage.
- Use built-in food reference data when online databases are unavailable.

## Technologies Used

- HTML
- CSS
- JavaScript
- Electron
- Local Storage
- CalorTracker API
- Open Food Facts API

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install the dependencies:

   `npm.cmd install`

5. Start the application:

   `npm.cmd start`

## Disclaimer

NutritionPlan is designed for learning and general food planning purposes. It is not intended to provide medical advice. Nutritional values may vary, so check the actual food label when accuracy matters.
